# IT-Slang Dictionary: Система управления терминологией IT-жаргона

## 📖 Описание проекта
**IT-Slang Dictionary** — это веб-приложение для систематизации, изучения и анализа современного IT-жаргона. Проект решает проблему хаотичности технической лексики, предоставляя структурированную базу данных с лингвистическим анализом, семантическими связями и фонетической адаптацией заимствований.

Проект разработан на стеке **Python (Flask) + SQLite + HTML/CSS/JS** и реализует полный цикл работы со словарными данными: от администрирования до пользовательского поиска с умной фильтрацией.

---

## 🚀 Ключевой функционал

### 1. Лингвистическая база данных
*   **Многозначность и омонимия:** Поддержка нескольких определений для одного термина (нумерованный список). Каждое значение может иметь свои стилистические пометы и примеры употребления.
    *   *Пример:* Термин "Костыль" имеет значения: 1) Временное решение в коде; 2) Инструмент сборки.
*   **Грамматическая информация:** Для каждого термина указаны часть речи, род, число, вид глагола и другие морфологические характеристики (например: "сущ., м.р., нескл.", "гл., несов. вид").
*   **Этимология и происхождение:** Поля для указания исходного слова (origin), языка-источника и года первой фиксации в речи.
*   **Фонетическая транскрипция:** Уникальная система записи произношения англоязычных заимствований кириллицей, основанная на реальном произношении в русскоязычном IT-сообществе (с учётом редукции гласных, оглушения согласных и постановки ударения).
    *   *Пример:* `debug` → `[дъба́г]`, `Kubernetes` → `[кубʌрн´эт'ис]`.

### 2. Семантический анализ
*   **Связи между терминами:** Реализована система графовых связей трех типов:
    *   **Синонимы:** Слова с близким значением (напр., "Дебажить" ↔ "Отлаживать").
    *   **Антонимы:** Слова с противоположным значением (напр., "Бэкенд" ↔ "Фронтенд").
    *   **Родственные понятия:** Ассоциативные связи.
*   **Визуализация:** На странице термина выводится блок "Семантические связи", где синонимы и антонимы визуально разделены цветом.

### 3. Пользовательский интерфейс
*   **Умный поиск:** Мгновенная фильтрация терминов по названию, определению или категории без перезагрузки страницы (JavaScript).
*   **Алфавитный сайдбар:** Быстрая навигация по первой букве термина.
*   **Карточка термина:** Детализированное отображение всей информации: транскрипция, грамматика, нумерованные определения с примерами, категории и семантические связи.
*   **Адаптивный дизайн:** Современный UI с использованием CSS-переменных, теней и анимаций.

### 4. Административная панель
*   **CRUD операции:** Полное управление базой терминов (создание, чтение, обновление, удаление).
*   **Динамические формы:** Возможность добавлять неограниченное количество определений и примеров прямо в интерфейсе редактирования.
*   **Управление связями:** Выпадающие списки для выбора связанных терминов с указанием типа связи.
*   **Защита:** Авторизация через Flask-Login.

## 🛠 Технический стек
*   **Backend:** Python 3.10+, Flask, Flask-SQLAlchemy, Flask-Login, Flask-WTF.
*   **Database:** SQLite (легковесная БД, легко мигрируемая на PostgreSQL).
*   **Frontend:** HTML5, CSS3 (Flexbox/Grid, анимации), Vanilla JavaScript.
*   **Deployment:** Gunicorn, Render/Heroku compatible.

## 📜 История разработки (Путь проекта)

Разработка велась итеративно, с последовательным внедрением сложных лингвистических функций:

1.  **Базовая версия:** Простой словарь "слово — определение". Одна запись — одно значение.
2.  **Реализация многозначности:** Переработка модели данных для поддержки списка определений (`One-to-Many` связь Term ↔ Definition). Внедрение нумерации значений и индивидуальных примеров для каждого смысла.
3.  **Грамматический модуль:** Добавление полей для морфологической разметки (транскрипция, часть речи, род), что позволило использовать словарь как учебное пособие.
4.  **Семантическое ядро:** Внедрение системы связей (Синонимы/Антонимы). Потребовало создания отдельной таблицы отношений и рефакторинга форм редактирования для выбора парных терминов.
5.  **Фонетическая адаптация:** Разработка и внедрение авторских правил транскрибирования IT-жаргонизмов на кириллицу. Отказ от академической IPA в пользу практической записи, отражающей реальное произношение разработчиков (редукция, оглушение, ударение).
6.  **UI/UX улучшения:** Оптимизация навигации (сайдбар), внедрение живого поиска, улучшение визуальной иерархии карточек терминов.

## 📋 Инструкция по запуску

### Требования
*   Python 3.8+
*   pip

### Установка
1.  Клонируйте репозиторий:
    ```bash
    git clone <url-репозитория>
    cd it-slang-dictionary
    ```

2.  Создайте виртуальное окружение и активируйте его:
    ```bash
    python -m venv venv
    # Windows
    venv\Scripts\activate
    # Linux/Mac
    source venv/bin/activate
    ```

3.  Установите зависимости:
    ```bash
    pip install -r requirements.txt
    ```

4.  Инициализируйте базу данных (если она не создана автоматически):
    ```bash
    python app.py
    # Приложение создаст файл instance/dictionary.db при первом запуске
    ```

### Запуск
```bash
python app.py
```
Откройте браузер по адресу: `http://127.0.0.1:5000`

**Доступ к админ-панели:**
*   URL: `/admin`
*   *(Логин и пароль устанавливаются при первоначальной настройке или через БД)*
